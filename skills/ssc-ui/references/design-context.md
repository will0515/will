# Design Context

## User

The primary user of this skill is a UI designer building B-end product pages for personal project work. The goal is to move quickly from product requirements to page output without rebuilding the same structure each time.

## Product Type

Default to internal or enterprise-facing admin products:

1. Management backends
2. Configuration centers
3. Organization and member management
4. Service or system management
5. Data-heavy workflow pages

## Visual Direction

Keep the default tone:

1. Professional
2. Stable
3. Efficient

Prefer a light background, soft neutrals, green accents, clear hierarchy, and low visual noise. Prioritize fast scanning, clear data grouping, and predictable interaction patterns.

## Working Principles

1. Let requirements drive page structure, not random visual invention.
2. Reuse existing components before creating new ones.
3. Extend existing component families before introducing isolated patterns.
4. Update the system whenever a new reusable pattern appears.
5. Keep the output easy to hand off to front-end development.

## Default Language

Write page planning, component notes, and delivery summaries in Chinese unless the repo or the user clearly wants English.
